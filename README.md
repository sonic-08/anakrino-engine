# ✨ Overview

Anakrino Engine is an intelligent AI discovery platform that helps users find the best AI tools for any task.

Instead of showing random search results, Anakrino uses **Google Gemini with live Google Search** to analyze the user's request and return curated AI platforms with:

- Tool descriptions
- Pricing information
- Categories
- Pros & Cons
- Official website links

The project combines modern UI design with AI-powered search to create a fast and premium user experience.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/sonic-08/anakrino-engine.git
```

Move into the project

```bash
cd anakrino-engine
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

---


# 🧠 How It Works

1. User enters a search query.

2. The query is sent to Google Gemini.

3. Gemini performs a live Google Search.

4. The model generates structured JSON containing:

- AI Tool Name
- Description
- Pricing
- Category
- Pros
- Cons
- Official Website

5. React renders the recommendations in a premium interactive interface.
